# Craft：建模与镜头

把说明书演成「一眼能认出的真东西」，而不是方块拼图。规则来自鼠标案例和场景审计抓到的问题。

## 1. 坐标与朝向

- 世界：毫米，**Y 向上**，地面 **y = 0**，观众默认在 **+Z**。
- 产品局部「前方」写进脚本文件头（鼠标：滚轮方向 = **-z**）。左右按用户正常使用视角。
- 平面形体（`hole` / `led` / `screen` / `text`）默认朝 **+Z**，用 `rot`（度，XYZ）转向。
- **翻面**：本体 `{ at: [x, 高度, z], rot: [0, 0, 180], lift, dur: 1.4 }`。翻面后左右镜像——底视图左侧 = 局部 +x（绕 z 180° 后从上方看）。

朝向速查见 [reference.md](reference.md)。

## 2. 零件怎么建

| 原则 | 做法 |
|---|---|
| 最少形体讲清步骤 | `shell` / `slab` / `box` / `cylinder` / `hole` / `led` / `screen` / `text` / `compound` / `cable` |
| 跟着走 | 子零件挂 `parent`；插进电脑的配件用 `plug` 换父级 |
| 贴曲面 | `at: { on: [x, z], dy }`（父级必须是 `shell`） |
| 别堆细节 | < 1.5 mm 不建，靠 `zoom` + 标注 |
| 规模 | 零件 ≤ 60；`stageSize` ≤ 1500 |

**插头约定**：原点在插头与外壳交界，插头朝局部 **+x**。插口是 `hole`，默认平面朝 +Z（接口外法线）。用 `plug` 时编译器会对齐：插头 +x → 接口内部，+y → hole 的高，+z → hole 的宽。

**底面凸出件**（拨钮、收纳里的接收器）：平放时最低点 ≥ 0。拨钮中心 y 取半高略上（如高 1.6 → y≈0.35）；接收器收纳时底面与鼠标底面齐平。

**场景道具**（电脑 / 手机 / 插座）：只建到能讲清步骤——接口位置准、屏幕能显示即可，不必复刻键盘每个键。

## 3. 步骤动作

- 一条原文指令 = 一步；标题动词开头。
- `set` 只写变化；状态自动累积。
- **插入**：`{ plug: 'port-la2' }` 或 `{ plug: { hole, roll?, depth?, back? } }`。不要手写 `parent`/`at`/`rot`/`via`（与 `plug` 互斥）。`back` 是外侧途经距离（默认 30）；`back: 0` 表示沿插入轴推进（插紧）。
- **拔出**：`{ parent: null, at: 世界坐标, via: 仓口正上方, lift? }`，via 避免穿出机体。
- **绕开障碍**：两侧之间横穿用 `via` 绕到前方/上方（鼠标案例的 `FRONT`），并加足够 `lift`。
- **同一步先后**：`delay` / `dur`（翻面 1.4s 后再拨开关 delay 1.6）。
- **动作循环**（不改状态）：`press` / `spin` / `shake` / `glide`。
- 指南起点：`initial`（共用）+ `guide.start`。

## 4. 镜头与标注

| 用途 | dist（约） | 备注 |
|---|---|---|
| 总览 | 1000–1300 | 可加 `orbit: true` |
| 产品近景 | 250–450 | |
| 接口区 | 400–500 | 斜看，别正对端面 |
| 细节窗 zoom | 70–140 | 目标占圆窗足够大；底部灯用 `dir: 'under'` |

- `highlight`：本步操作件（红色线稿）。有移动就该有 highlight 或 callout。
- `callouts` ≤ 6；近景 offset 25–50 mm，远景 60–100 mm；左右错开，避开右上细节窗。
- 小件（< 15 mm）必配 `zoom`，`caption` 写结论（「黄灯闪烁 = 电源正常」）。
- 每步写 `page`；注意写 `tip`；数值写 `chips`。

## 5. 灯、屏幕、线缆

- 灯：`light` = `off` / `on` / `blink` / `blinkThenOff`；亮起时主画面或细节窗必须能看到正面。
- 屏幕：`ui` 用线稿系统界面（见 `ScreenUI`）；选中 / 完成用 `state`。
- 线缆：两端插头各自 `plug` / 换父级，线缆零件引用两端；调 `slack` 防穿模。拔出时给插头加 `via` 绕开主机。

## 6. 反模式（审计或截图会抓到）

- 手算插入姿态却对不齐接口 → 用 `plug`。
- 底面拨钮 / 接收器穿地 → 抬高局部 y。
- 鼠标贴桌面横穿笔记本 → `via` + `lift`。
- 底部灯亮着却只从上方拍 → `zoom` + `dir: 'under'`。
- 丝印 `rot` 写反 → 细节窗里是镜像字。
- 近景标注还用远景 offset → 飞出画面或挡细节窗。
- 高亮小零件却无 zoom → 读者看不见。
- 一步过渡 > 6 s → 拆步。
