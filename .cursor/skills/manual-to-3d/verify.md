# Verify：审计与截图

渲染便宜，猜很贵。先让机器量，再自己看图。

## 命令

```bash
npm run check:manuals              # 脚本校验 + 场景审计；须 audit passed
npm run check:manuals -- mouse-bt54
npm run audit:selftest             # 改过 audit.ts 后跑：每项埋一个故障必须报出
npm run shoot -- <id>              # 逐步截图 + 每指南一张联系表 → shots/<id>/
npm run shoot -- <id> --guide usb-a
npm run shoot -- <id> --phone      # 390×844
npx tsc --noEmit && npm run build
```

需要 Chrome（或设 `CHROME_PATH`）。`shots/` 已 gitignore。

## 场景审计（`check:manuals`）

对每个指南每一步：静止姿态 + 过渡途中抽样帧（与 `ManualStage` 同一套 `pose.ts`）。

| 检查 | 含义 | 修法 |
|---|---|---|
| 穿地 | 实体最低点 < −0.5 mm | 抬零件 / 拨钮 y；翻面过渡加 lift |
| 穿插（静止） | 无亲缘关系实体重叠 | 改 at / 尺寸；父子挂接别当穿插 |
| 穿插 / 穿地（途中） | 过渡中穿过物体或地面 | `via` 绕开、加大 `lift`、错开 `delay` |
| 插接 | 多插头同口；插在隐藏接口上 | 检查 `plug` 目标 |
| 镜头 | 高亮件出画 / 始终隐藏 | 调 camera；斜看接口 |
| 细节窗 | 目标隐藏、背对、或太小 | 调 zoom.dist / dir |
| 指示灯 | 亮着但正面不可见 | 加 under zoom 或改镜头 |
| 标注 | 锚点/标签出画、重叠、挡细节窗 | 调 offset；≤6 个 |
| 镜像文字 | 镜头从文字背面看 | 改 text 的 rot |
| 步骤 | 无 page、无高亮、空 set、过长 | 补字段或拆步 |
| baked | 原位的 baked 件被高亮或按（原位时只有模型里那份，看不到） | 做成几何体：参考图抹平重新生成，去掉 baked（reference.md「一物一画」） |
| 悬空 | note：手持配件离地（只阅读） | 通常合法 |

输出末行须为 `audit passed`。warnings 也要逐条看过再忽略。

`npm run audit:selftest`：在鼠标副本上各埋一个故障，十项检查都必须报出，否则审计本身坏了。

## 截图（`shoot`）

脚本会：启动 Vite → 无头 Chrome → 逐步 `setGuide`/`go` → 等镜头飞完 → 把动画时钟拨到过渡结束后（闪烁灯取亮的半周期）→ 截全页 → 拼联系表。

读每一张 PNG（含 `*-sheet.png`），对照下面清单。后台标签页会节流 rAF——**不要**用「另开标签手动截」代替本脚本。

## 人工清单

**空间**
- [ ] 无穿地、无穿插；插头确实进了接口
- [ ] 线缆未打结、未穿实体
- [ ] 翻面后左右与说明书底视图一致

**可读**
- [ ] 丝印/文字无镜像
- [ ] 高亮件在画面内；小件细节窗看得到结论
- [ ] 标注在画内、不重叠、不挡细节窗（桌面与手机）
- [ ] 指示灯正面可见（底部灯看 under 窗）
- [ ] 屏幕界面字完整；页码 chips 正确

**写实（挂了外观模型的，`shoot --real`）**
- [ ] 没有两层：模型自带的按键 / 屏幕 / 指示灯上又叠了一套几何体（审计看不出来，只能看图）。有就按 reference.md「一物一画」重新生成抹平的模型
- [ ] 几何按键和照片里的真按键位置、形状一致，没有浮在模型表面外或陷进去
- [ ] 拆开、折叠、打开的每一步放大看切口（`--scale 3`）：切面是平整的封口，没有锯齿边、空心的壳、碎三角、透到背景的缝；动的那块没有带走相邻的壁（车身上没留洞）
- [ ] 一个模型切成几块的，原位时几块拼得严丝合缝（同一个 `frame`），会动的件不是 `baked`（一动父零件就变代理方块）

**节奏**
- [ ] 每步一眼知道看哪；插入路径从外侧进
- [ ] 联系表上没有「空步」或莫名其妙的中间姿态

## 常见故障

| 图上看到 | 修 |
|---|---|
| 拨钮陷进桌面 | 拨钮局部 y 抬到半高以上 |
| 接收器拔出时穿鼠标壳 | 拔出加 `via` 到仓口正上方 |
| 靠近接收器时穿过笔记本 | `via` 绕前方 + `lift` |
| 细节窗里灯是黑的 | 截在闪灭半周期——shoot 已处理；手截时换时间点 |
| 接口正对只看见插头端面 | camera 改斜向 |
| 手机上标注飞出 | 减小 offset 或挪到对侧 |
| 写实下按键 / 屏幕糊成两层、互相遮挡 | 模型里也有它：参考图抹平后重新生成（`scripts/ref-cover.mjs`），几何体按照片重新排 |
| 写实下几何按键不见了（线稿里也没有） | 陷进模型里了：模型拉伸后的表面比代理表面高，按 reference.md「一物一画」量出模型表面，把键挪上去 |
| 拆开 / 折叠后切口是碎面、锯齿、透背景的缝 | 框边擦着薄边或接缝走：`npm run model:section` 量截面，把框边挪到横穿细杆的位置（reference.md「一个模型切成几块」） |
| 零件动起来以后，原来的位置留下一个洞、动的件上挂着一块板 | 框把贴得很近的壁一起挖走了：截面图量出两件之间的空隙，框边放进空隙 |
| 折叠 / 打开那几步父零件变成黑方块 | 会动的件写了 `baked`：改成从模型里切出来（`crop.cut` + `frame`） |
