# 折纸程序参考

## 零件

```json
{ "id": "sheet", "name": "纸", "shape": {
  "type": "origami", "size": 150, "color": "#d8404b", "ops": [ … ] } }
```

| 字段 | 说明 |
|---|---|
| `size` | 正方形边长，或 `[宽 x, 长 y]`（mm）。A4 = `[210, 297]` |
| `color` | 彩色面，`#rrggbb`，缺省 `#e4573d` |
| `white` | 另一面，缺省 `#f7f4ec`；双面同色的纸写成和 color 一样 |
| `up` | 开始时朝上的一面：`'white'`（缺省）/ `'color'` |
| `th` | 纸厚，缺省 0.3 mm（比真纸厚，画面上看得出层次）；一般不写 |
| `ops` | 折纸程序：第 k 个 op 执行完 = 第 k 步 |

纸平铺在桌面（y = 0）、中心在原点。一份脚本只放这一张纸；别的道具（桌子、手）都不要。

## 坐标

**图解坐标 `[x, y]`（mm）**：从正上方看桌面，x 向右，y 朝远离观众的方向（= 图解上的「上」）。
永远是**纸当前摆在桌上的位置**：折过之后，角和边都换了地方，按新位置写。

- 正方形 150 mm 平放：四个角 `[±75, ±75]`。
- 先 `turn 45` 摆成菱形：上角 `[0, a]`、下角 `[0, −a]`、左右角 `[±a, 0]`，a = 75√2 ≈ 106.1。
- A4 竖放：`[±105, ±148.5]`，上边中点 `[0, 148.5]`。

每一步之后纸自动「落地」（最低点 y = 0）。`flip` 和 `turn` 绕当前包围盒的中心转，所以翻面 / 平转之后纸还在原处，但坐标跟着变了。

`rotate` 的 `at` / `axis` 是**三维**零件坐标 `[x, y, z]`：x 向右、y 向上、z 朝观众，所以 z = −（图解 y）。

## op

### fold：沿直线折

```json
{ "op": "fold", "bring": [0, -106.1], "onto": [0, 106.1] }
{ "op": "fold", "line": [[0, 148.5], [0, -148.5]], "move": [-50, 0] }
{ "op": "fold", "line": [[-106, 26.5], [106, 26.5]], "move": [0, 100], "under": true, "only": { "moved": 2 } }
```

- `bring` + `onto`：把 bring 点折到 onto 点上，折线是两点连线的中垂线，bring 那一侧翻过去。**「角折到角 / 角折到中心 / 角折到中线上某点」都用它**，不用自己算折线。
- `line` + `move`：沿两点连线折，move 是要翻过去那一侧的任意一点（不能正好在线上）。line 的两个点可以在纸外面（延长线），只要直线对。
- 缺省是**谷折**：翻过去的那片往上翻、压平 180°，盖在另一侧上面。
- `under: true` = **山折**：往下翻，压到另一侧底下（「往后折」）。
- `angle`：只转这么多度（0–180），比如 90 = 立起来一半；缺省 180 压平。
- `only`：只折选中的面（见下）。**不写时折线那一侧的所有层一起翻**（整叠一起折）。

### unfold：打开第 step 步

```json
{ "op": "unfold", "step": 1 }
```

把第 step 步翻过去的面翻回原位，留下一条折痕（之后的画面里是浅色的线）。「对折压出中线再打开」= fold + unfold。

### flip：整张翻面

```json
{ "op": "flip" }                       // 左右翻（绕纵轴，缺省）
{ "op": "flip", "way": "top-bottom" }  // 上下翻
```

翻面后左右（或上下）互换：原来在 `[x, y]` 的点现在在 `[2cx − x, y]`（cx = 包围盒中心）。后面的坐标按翻过之后写。

### turn：在桌上转

```json
{ "op": "turn", "angle": 45 }
```

俯视逆时针为正。开始时把正方形摆成菱形就是 `turn 45`。

### rotate：立体造型（各组同时转）

```json
{ "op": "rotate", "groups": [
  { "only": { "moved": 9 }, "crease": 9, "angle": -100 },
  { "only": { "moved": 10 }, "crease": 10, "angle": -100 } ] }
{ "op": "rotate", "groups": [ { "at": [0, 0, 26.5], "axis": [1, 0, 0], "angle": 70 } ] }
```

- `crease: k`：绕第 k 步那条折痕转。**正数 = 顺着第 k 步的方向继续折，负数 = 往回打开**。压平的翅膀打开到水平是 −90，再多 −10 就是 10° 上反角（−100）。
- 或者 `at` + `axis`（三维，右手定则）：绕任意轴转，比如绕底边把整张纸立起来。
- `only` 选要转的面（缺省全部）。同一步里已经被前面一组转过的面不会再转。

### stand：整张立起来

```json
{ "op": "stand", "crease": 8 }
{ "op": "stand", "crease": 9, "angle": 80 }
```

绕第 crease 步的折痕把整张纸转 angle 度（缺省 90），自动选让纸离开桌面的方向。纸飞机沿机身底边立起来、纸杯沿杯底立起来都用它。

### draw：在纸上画点

```json
{ "op": "draw", "marks": [ { "at": [-16, -32], "r": 4.5 }, { "at": [16, -32], "r": 4.5 } ] }
```

画在这个位置最上面那层朝上的一面（眼睛、鼻子）。`color` 缺省黑色。之后跟着纸一起动。

## 选层 only

| 写法 | 选中 |
|---|---|
| `"all"` | 全部（缺省） |
| `{ "moved": k }` | 第 k 步翻动过的面（「第 3 步折下来的那片」） |
| `{ "flap": [x, y] }` | 这个位置最上面那层所在的一片（和它一起被翻动过的面） |
| `{ "not": S }` | 除了 S |
| `{ "any": [S1, S2] }` / `{ "every": [S1, S2] }` | 并集 / 交集 |

常见用法：
- 「只把前面一层往上折」：`{ "moved": 对折那一步 }`（对折时翻过来的那片就是前层）。
- 「后面一层往后折」：`{ "not": { "moved": 对折那一步 } }` + `under`。
- 「另一边机翼也折下来」：第一边用 `{ "not": { "moved": 机身对折那一步 } }`，第二边用 `{ "moved": 机身对折那一步 }` + `under`。
- 纸杯撑开杯口：前片 `{ "not": 后片 }`、后片 `{ "every": [ { "not": { "moved": 2 } }, { "not": { "moved": 3 } }, { "not": { "moved": 4 } } ] }`，两组绕同一条杯底折痕一正一负。

## 图解符号 → op

| 图解 | op |
|---|---|
| 虚线（谷折线）+ 箭头翻过来 | `fold`（缺省） |
| 点划线（山折线）+ 箭头往后 | `fold` + `under: true` |
| 箭头折过去又回来（压折痕） | `fold` + `unfold`（两步） |
| 翻转箭头（圆圈里一个弯箭头） | `flip` |
| 旋转符号 / 「转 90°」 | `turn` |
| 「把角塞进口袋」 | 在口袋那一层上面谷折（`only` 选这只角），层次上压在口袋外层**底下**时用 `under` |
| 「拉开 / 撑开 / 打开翅膀」 | `rotate`（crease = 当初折这一片的那一步，负角度） |
| 「立起来」 | `stand` |
| 「画上眼睛」 | `draw` |
| 内翻折、外翻折、压平折、花瓣折、沉折、收拢 | 不支持：找简化版或换作品 |

## 常见起手

```json
// 正方形摆成菱形，压十字折痕
{ "op": "turn", "angle": 45 },
{ "op": "fold", "line": [[0, -106.1], [0, 106.1]], "move": [-100, 0] },
{ "op": "unfold", "step": 2 },
{ "op": "fold", "line": [[-106.1, 0], [106.1, 0]], "move": [0, 100] },
{ "op": "unfold", "step": 4 }

// 下角对折到上角（三角形）
{ "op": "fold", "bring": [0, -106.1], "onto": [0, 106.1] }

// 风筝基本型：两条下斜边折到竖直中线（先压过竖直中线）
// 左角离下角 150 mm（一条边长），折到中线上同样离下角 150 mm 的点：y = −106.1 + 150 = 43.9
{ "op": "fold", "bring": [-106.1, 0], "onto": [0, 43.9] },
{ "op": "fold", "bring": [106.1, 0], "onto": [0, 43.9] }

// 坐垫基本型：四个角都折到中心
{ "op": "fold", "bring": [0, 106.1], "onto": [0, 0] }, … 另外三个角同理
```

## TS 样板（库里的作品用）

```ts
import { Paper } from '../origami'
const paper = new Paper({ size: 150, name: 'cup', color: '#2a9d8f' })   // name = 零件 id
const diamond = paper.turn(45)                     // 每个方法返回步号 k
const half = paper.fold([-a, 0], [a, 0], [0, -a + 5])
const right = paper.bring([a, 0], [-(a - t), t])
const front = paper.fold([-a, t], [a, t], [0, a - 5], { only: { moved: half } })
const stand = paper.stand(half)
// spec：parts: paper.parts()；步骤：camera: paper.view(k, dir), set: paper.set(k), highlight: paper.movedIds(k)
// 第二个指南：start: paper.state(k)；整张纸一起动（扔出去）的动作挂在 paper.carrier 上
// 细节窗对准纸上某一点：paper.where([x, y], k) 给出这个点在第 k 步的三维位置
```

## 网站导入（JSON）

- ops 全部写成字面量（最多 1 位小数），算好的数（a = 106.1、t = 62.1）直接写数字，在 notes 里写推导。
- 步骤只写 `"set": { "<纸 id>": { "fold": k } }`；第 0 步写 `fold: 0`。
- **镜头只写 `"camera": { "dir": [x, y, z] }`**：服务器按那一步纸的形状补 target 和 dist。要特写写 `"camera": { "dir": [...], "dist": 数值, "target": [x, y, z] }`。
- `highlight: ["<纸 id>"]`：本步翻动的面自动提亮。
- 不写 `model` / `finishes` / `parent` / `plug`；不写别的零件。

## 引擎报错

| 报错 | 原因 / 改法 |
|---|---|
| 折线 move 那一侧没有选中的纸 | move 点选错了侧，或 only 选的面都在另一侧 |
| move 点在折线上 | move 换一个离线远一点的点 |
| bring 和 onto 是同一个点 | 两个点重合（坐标写错了，可能没考虑前面的翻折） |
| only.moved 要是前面的步号 | 步号从 1 数，只能引用已经执行过的步 |
| [x, y] 这个位置没有纸 | draw / flap 的点落在纸外：按当前位置重算 |
| 第 k 步的折痕旁边找不到没翻动的面 | rotate / stand 引用的那一步，被翻动的面两侧都动过了：换一条折痕或用 at + axis |
| fold 要是 0–N 的整数 | 步骤 set 里的 fold 超过了 ops 数 |
