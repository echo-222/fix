# 折纸演示复核清单

截图联系表每格是一步折完的样子。对照参考教程的图，逐格看：

## 每一格

- [ ] **形状对**：轮廓和教程这一步的图一致（三角、风筝、菱形……），尺寸比例对。
- [ ] **翻过去的那片在上面**：谷折的那片盖在上面、山折的那片压到底下。层次反了 = `under` 写反了，或 only 选错了层。
- [ ] **颜色面对**：这一步该露出彩面的地方是彩色、该是白面的是白色（白面朝上开始折，折过来的那片露出彩面）。整张颜色反了 = `up` 或少了一次 `flip`。
- [ ] **连续**：纸没有断开、没有漂在空中的碎片；折边是圆弧，打开的折痕是一条浅线。
- [ ] **本步高亮**：本步翻动的面是提亮 / 描粗的；其它面正常。
- [ ] **镜头**：纸在画面中间、占画面一半左右；山折的步骤能看到背面那片；不要从正上方看立体的步骤。
- [ ] **点 / 标记**：画上的眼睛鼻子在正面，位置左右对称。

## 整体

- [ ] **对称**：对称作品左右一样（`origami-probe` 的镜像误差 < 1 mm）。
- [ ] **最后一步是立体的**：成品立起来 / 撑开 / 翅膀张开，有明暗和投影，一眼认得出是什么。
- [ ] **步数和教程对应**：一张图一步，「折了再打开」拆成两步；没有漏掉压折痕的步骤（后面的折线常以它为准）。
- [ ] **文字和画面一致**：title / desc 说的方向（往上、往后、左边、右边）和画面一样。

## 常见错误和改法

| 现象 | 改法 |
|---|---|
| 折过去的那片钻到下面去了 | 谷折不要写 under；或者 only 漏了，把下面的层也一起翻了 |
| 整叠纸一起翻了，教程只折最上面一层 | 加 `only: { moved: k }` 或 `{ flap: [x, y] }` |
| 折线位置偏了一点，成品歪 | 改用 `bring` / `onto` 点对点；坐标按上一步之后的位置重算 |
| 翻面之后左右反了 | flip 之后 x 坐标镜像：`x → 2cx − x` |
| 立体收尾转错方向（翅膀往下） | rotate 的 angle 正负号反过来（正 = 继续折，负 = 打开） |
| 成品太小 / 太大 | 镜头 dir 不变，删掉 dist 让服务器重新取景；或调 dist |
