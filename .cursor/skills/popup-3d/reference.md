## 纸片 sheet 与 edges

```json
{ "id": "page", "name": "卡片上半张", "shape": { "type": "sheet", "points": [[-108, -139.5], [108, -139.5], [108, 0], [-108, 0]], "back": "warm", "backFinish": { "color": "#3f7fc4", "roughness": 0.85 } },
  "fill": "white", "finish": "paper" }
```
- `points` 是俯视轮廓 `[x, z]`（零件局部坐标，不自交，顺逆时针都行），纸厚 `th` 缺省 0.3，占 y ∈ [0, th]。
- 正面（+y）用 `fill` / `finish`，背面用 `back` / `backFinish`。画了图的那面朝哪，决定了合上 / 打开时读者看到什么。
- `edges`（写在状态里）：第 i 个字符画 `points[i] → points[i+1]` 这条边（最后一个字符是收尾边）。`h` 黑线（纸边、剪口）、`s` 浅灰（压过的折痕、铅笔线）、`-` 不画（还没剪 / 还没折出来）。字符数必须等于点数。
- sheet 不能挖洞。开窗（窗口卡、相框）用一条零宽的「桥」从外框走进窗口，窗口反着绕一圈再原路出来，桥的两条边写 `-`：

```json
"points": [[-66, -51], [66, -51], [66, 51], [-66, 51], [-66, -35], [-35, -35], [-35, 35], [35, 35], [35, -35], [-35, -35], [-66, -35]],
"edges": "hhhh-hhhh-h"
```
（外框 132 × 102，中间 70 × 70 方窗。外框和窗口的绕向必须相反。）
- 圆片：24–40 个点的正多边形，`[r·cos(2πi/n), −r·sin(2πi/n)]`。

## 坐标：两种对折方向

**横着对折（上下翻，贺卡最常见）**：中缝沿 x 轴、在 z = 0。下半页 `base` 平放，z ∈ [0, D] 朝观众；上半页 `page` 的轮廓 z ∈ [−D, 0]，`rot: [α, 0, 0]`：α = 0 摊平、90 竖直、180 合上。卡片张角 θ = 180° − α。
**竖着对折（左右翻，书本）**：中缝沿 z 轴、在 x = 0。右页 `base` 平放 x ∈ [0, W]；左页 `page` 轮廓 x ∈ [−W, 0]，`rot: [0, 0, −φ]`：φ = 0 摊平、180 合上。

书页翻动一定要写 `arc`（绕中缝转，不走直线），正好转 180° 时写 `axis` 定方向：
```json
"page": { "rot": [180, 0, 0], "arc": { "at": [0, 0.85, 0], "axis": [1, 0, 0] }, "dur": 1.6 }
```
打开时 axis 反过来（`[-1, 0, 0]`）。所有跟着书页动的纸片用**同一个 `dur` / `delay`**，过渡途中联动才不散。

## 层高与转轴（pivot）

合上时纸叠在一起，每片纸要有自己的 y 区间（纸厚 0.3，层间至少 0.05），否则审计报穿插、画面闪。先列一张表，例如平行折：

| 合上时从下往上 | y 区间 |
|---|---|
| 下半页 base | [0, 0.3] |
| 装饰卡 | [0.35, 0.65] |
| 小条 A | [0.7, 1.0] |
| 小条 B | [1.05, 1.35] |
| 上半页 page | [1.4, 1.7] |

翻转 180° 的纸片：转轴抬到高度 h，`pivot: [0, p, 0]` 把纸面挪回去。摊平时纸占 [h + p, h + p + 0.3]，翻过来后占 [h − p − 0.3, h − p]。
- 书页：`at: [0, H, 0]`、`pivot: [0, −H, 0]` → 摊平 [0, 0.3]，合上 [2H − 0.3, 2H]。上面的表 H = 0.85。
- 挂在书页上的纸片，位置写在书页的局部坐标里，同样用这个公式（书页合上时它的局部 +y 朝下）。

## 铰链零件（ghost）

纸片要绕一条斜线转时，不要直接写组合欧拉角，加一个看不见的铰链当父零件：
```json
{ "id": "hinge-b", "name": "右片粘贴线（铰链）", "parent": "base", "at": [0, 0.35, 30], "rot": [0, 45, 0], "shape": { "type": "text", "text": " ", "size": 0.5 } },
{ "id": "wing-b", "name": "山峰右片", "parent": "hinge-b", "shape": { "type": "sheet", "points": [[0, 0], [70, 0], [0, 85]], "back": "warm", "backFinish": { "color": "#5c9e6c" } }, "fill": "white", "finish": "paper" }
```
- 铰链 `rot: [0, θ, 0]` 让它的局部 +x 指向世界 `(cos θ, 0, −sin θ)`：把折痕方向换算成 θ 就行。纸片的折痕画在自己的局部 x 轴上，状态里只改纸片的 `rot: [ψ, 0, 0]`（绕折痕转 ψ）。
- 铰链必须**可见**（shape 用一个空格的 text，画面上看不到）：`visible: false` 的父零件会把子零件一起藏掉。
- 绕 x 轴转 ψ：局部 +z 转到 `(0, −sin ψ, cos ψ)`。纸片在折痕 +z 一侧时，ψ = −90 立起来；在 −z 一侧时，ψ = +90 立起来。拿不准就截图看，转反了纸会钻到书页下面（审计报穿地 / 穿插）。

## 机关一览

### 平行折（盒子、台阶）——精确

横着对折，从中缝剪两条平行口（长 L、间距 w），中间的小条推进卡片里。小条分两片：A（盒子前面）挂在 base 上、铰链在 z = L；B（盒子顶面）挂在 page 上、铰链在 page 局部 z = −L。
```json
{ "id": "flap-a", "parent": "base", "at": [0, 0.5, 51], "pivot": [0, -0.5, 0], "shape": { "type": "sheet", "points": [[-32, 0], [-32, -51], [32, -51], [32, 0]] } },
{ "id": "flap-b", "parent": "page", "at": [0, -0.525, -51], "pivot": [0, -0.325, 0], "shape": { "type": "sheet", "points": [[-32, 0], [32, 0], [32, 51], [-32, 51]] } }
```
书页转到 α 时：`page` 和 `flap-a` 都是 `rot: [α, 0, 0]`，`flap-b` 是 `rot: [−α, 0, 0]`（在 page 坐标里反着转），三片同 `dur`、各自 `arc` 绕自己的铰链：
```json
"set": {
  "page":   { "rot": [90, 0, 0], "arc": { "at": [0, 0.85, 0],    "axis": [-1, 0, 0] }, "dur": 1.6 },
  "flap-a": { "rot": [90, 0, 0], "arc": { "at": [0, 0.5, 51],    "axis": [-1, 0, 0] }, "dur": 1.6 },
  "flap-b": { "rot": [-90, 0, 0], "arc": { "at": [0, -0.525, -51], "axis": [1, 0, 0] }, "dur": 1.6 }
}
```
这样中缝、两条铰链、盒子棱永远是边长 L 的平行四边形：90° 时 A 竖直、B 水平，弹出一个 L × L 的盒子；摊平（α = 0）时两片收平回卡片里；合上（180°）时两片平躺在 base 上 z ∈ [L, 2L]。剪口长 L 要小于 D / 2，合上时才不露出卡外。

### V 形折（山峰、嘴巴）

竖着对折。一片沿中线（山脊）对折的纸，尖角压在中缝上 z = ZV 处，两条粘贴边各粘一页，和中缝成粘贴角 β；山脊和粘贴线成 V 角（下面按 90°）。打开时每片只绕自己的粘贴线转：
- 右片：铰链挂 base，`at: [0, 0.35, ZV]`，`rot: [0, 90 − β, 0]`；纸片在铰链局部 +z 一侧（山脊沿局部 +z），状态 `rot: [−ψ, 0, 0]`。
- 左片：铰链挂 page，`at: [0, −0.3, ZV]`（page 局部），`rot: [0, 90 + β, 0]`；纸片在铰链局部 −z 一侧，状态 `rot: [+ψ, 0, 0]`。
- 两片都是合上时 ψ = 0（平躺、叠在一起），书页摊平时 ψ = 90（山脊竖直）。中间的角度按下表（V 角 90°，书页 `rot: [0, 0, −φ]`）：

| 粘贴角 β | φ = 180（合上） | 135 | 90 | 45 | 0（摊平） |
|---|---|---|---|---|---|
| 30° | 0 | 19.7 | 40.9 | 64.4 | 90 |
| 45° | 0 | 16.3 | 35.3 | 59.6 | 90 |
| 60° | 0 | 11.7 | 26.6 | 50.4 | 90 |

关键帧是准的；过渡途中两片各自线性插值，山尖会稍微错开（1–2 mm），可以接受。规则写进 params：0° < 粘贴角 < V 角；粘贴边离中缝留 10 mm 以上不涂胶；尖角必须压在中缝上；合上时山尖不能超出卡片。

### 拉片 / 滑块

底卡上贴两条泡棉条当滑轨（薄 `box`，高 1.5），滑片（sheet）夹在中间、一端伸出拉手，最上面盖开窗的面板。拉动：
- 一步拉到底：滑片 `{ "at": [80, 0.4, 0], "dur": 1.2 }`；
- 循环演示：`"actions": [{ "type": "slide", "part": "slider", "axis": "x", "amp": 40, "period": 3, "clip": "pos" }]`。
滑片上的图跟着走就挂成滑片的子零件；窗口里露出的祝福语贴在底卡上（滑片下面一层）。

### 转盘

圆片挂在前面板背面的铆钉上（`parent: 'panel'`，`at` = 铆钉位置，y 比面板低 0.4 以上），面板上开一个小窗、边上剪缺口露出转盘边。转动：`{ "rot": [0, 90, 0], "dur": 1.5 }`（每格 360 / 格数），或 `spin` 循环（`axis: 'y'`，`speed` 0.1–0.2）。四季 / 表情这类分格画面：每格一个 text 或小纸片挂在转盘上。

### 翻盖、门

纸片的 `pivot` 把原点放到铰链边上（`pivot: [0, 0, −d/2]` = 铰链在后沿），状态 `rot` 绕铰链转，`arc` 写铰链点；转 180° 时写 `axis`。

### 层叠场景

前后几层景片各自固定高度，用泡棉垫（`box`，例如 8 × 1.3 × 8）垫起来；能立起来的景片就是一个平行折（同上）。层多的时候合上状态的层高表尤其要先列好。

## 制作道具

| 道具 | 形体 | 演示 |
|---|---|---|
| 铅笔 | compound：圆锥笔尖（cylinder r2 0.4）+ 杆（cylinder r 3.5） | `slide` 沿线来回，做完隐藏 |
| 美工刀 | compound：刀片（薄 box）+ 刀柄 | `slide` 沿剪口，刀片斜 35° |
| 胶棒 | compound：管身 cylinder + 白色胶头 | `slide` 涂在粘贴边上 |
| 尺子 | 薄 slab | 静止贴着要画的线 |

道具一出现就 `highlight`，用完 `visible: false, dur: 0.3`。

## 常见错误

| 现象 | 原因 / 修法 |
|---|---|
| 合上时纸片互相穿插、闪烁 | 层高表没列，几片纸在同一高度：按「层高」给每片单独的 y 区间 |
| 打开时小条飘在空中、离开书页 | 小条挂错了父零件，或 dur / delay 和书页不一样 |
| 盒子打开后不是方的 | 平行折两片的 rot 没有一正一反，或铰链位置不在 z = L / −L |
| 山峰钻到书页底下 | ψ 的符号反了：纸片在铰链 +z 一侧用负角，−z 一侧用正角 |
| 书页从桌子底下绕过去 | 转 180° 没写 arc.axis |
| 剪口一开始就画出来了 | 初始 edges 要把还没剪的边写成 `-` |
