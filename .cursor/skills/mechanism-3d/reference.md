## 动作的正负号

| 动作 | 公式 | 正方向 |
|---|---|---|
| `spin` | 每秒 speed 圈 | 从轴的**正方向**看**顺时针** |
| `swing` | θ = amp × sin(2π(t / period + phase)) | 右手定则（从轴正方向看**逆时针**） |
| `slide` | d = amp × sin(2π(t / period + phase))；有 `rod` 时 d = amp·sin x + √(rod² − amp²cos²x) − rod | 沿局部轴正向 |

动作作用在零件局部坐标：**原点就是转轴 / 滑动起点**，子零件跟着走。同一套机构的所有动作写同一个 `delay`；要从某个相位开始播，就给所有动作同一个负 `delay`（−相位 × 周期）。

## 齿轮

```json
{ "id": "gear-a", "name": "小齿轮 A", "at": [-90, 14, 0], "shape": { "type": "gear", "teeth": 12, "r": 18, "h": 10, "axis": "y", "bore": 3 } },
{ "id": "gear-b", "name": "中齿轮 B", "at": [-36, 14, 0], "rot": [0, 7.5, 0], "shape": { "type": "gear", "teeth": 24, "r": 36, "h": 10, "axis": "y", "bore": 3 } }
```
- `r` 是分度圆半径，模数 m = 2r / teeth；齿顶 r + m、齿根 r − 1.25m。**模数相同才能啮合**，中心距 = r₁ + r₂（上例 18 + 36 = 54）。
- 相位：齿 0 在局部 +x。两轮连线上一个必须是齿、一个必须是齿槽。偶数齿的轮在 ±x 两边都是齿，奇数齿的轮在 −x 是齿槽；对不上就给其中一个转半个齿距（`rot` 绕轴 180 / teeth 度，上例 B 转 7.5°）。连线不在 x 轴上时，按连线方向的角度换算。
- 转速：speed₂ = −speed₁ × z₁ / z₂（相邻反向，齿数反比）。惰轮只改转向不改传动比：A → B → C 时 speed_C = speed_A × z_A / z_C（同向）。
- 加记号点（深色小 cylinder 挂在齿轮上，离中心 0.6r），转速比才看得出来。
- 齿轮轴竖直（`axis: 'y'`，平放在底板上）最好看；发动机、钟表这类立面机构用 `axis: 'z'`，镜头从 +Z 看。

## 齿条

- `poly` 画齿形：节线上齿距 πm，齿高 2.25m（齿顶 m、齿根 1.25m），梯形齿（根宽约 0.3 齿距、顶宽约 0.15 齿距）。
- 齿轮 `swing`（amp α 度）+ 齿条 `slide`（amp = r × α × π / 180），同 period、同 phase。转一圈走 πm × z。
- 方向以截图为准：齿条往一边走时，齿轮在接触点的线速度要和它同向。

## 行星齿轮

- 齿数：Zr = Zs + 2Zp（同心）；(Zs + Zr) / 行星轮个数 = 整数（装配）；相邻行星轮不碰（邻接）。例：18 / 21 / 60，3 个行星轮。
- 内齿圈：`gear` 只有外齿，内齿圈用两块 `poly`（半圈带内齿的环）拼成。
- Willis 公式：(ωs − ωc) / (ωr − ωc) = −Zr / Zs。常用：齿圈固定（ωr = 0）→ ωc = ωs × Zs / (Zs + Zr)。
- 行星轮挂在行星架下（`parent: 'carrier'`），行星架 `spin` ωc，行星轮相对行星架自转 −(ωs − ωc) × Zs / Zp。

## 曲柄滑块（发动机、压缩机）

立面机构，轴沿 z，观众在 +Z：
- 曲轴：原点在曲轴中心，曲柄销在局部 +x 距离 r；`spin` axis z，speed = 1 / P。
- 活塞：静止位置（活塞销）= 曲轴中心 + (0, L, 0)；`slide` axis y，amp = r，rod = L，period P，phase 0.5。
- 连杆：活塞的子零件，原点在活塞销、杆朝 −y；`swing` axis z，`crank: true`，amp = asin(r / L)（度），period P，phase 0.25。
- 三个动作同一个 delay。四冲程：凸轮轴 speed = 1 / (2P)（半速）；四个冲程各一步，用负 delay 让每步从该冲程开始。
- 行程 = 2r；排量 = π/4 × 缸径² × 行程。

## 凸轮与从动件

- 凸轮：`poly` 画轮廓（基圆 + 凸起），挂在凸轮轴上一起 `spin`。
- 从动件：`slide`，amp = 升程，period = 凸轮转一圈的时间，`clip: 'pos'`（只在凸起经过时顶起）。phase 让顶起时刻对准凸起转到从动件下面的时刻：凸起在 t = 0 时离从动件的角度为 β（顺着转向量），顶起中点在 t = β / 360 × period，phase = 0.25 − t / period。
- 开启角比 180° 小（气门只开 240° 曲轴角 = 120° 凸轮角）时，用「驱动零件」叠两个 slide（见下），或接受半波近似并写进 notes。

## 连杆、摇杆

- 曲柄摇杆：曲柄 `spin`，摇杆 `swing`（同 period，amp = 摇杆摆角的一半，phase 按死点位置定）；连杆两端都动，用 `swing crank: true` 近似，或只做关键帧（状态里几个角度）。
- 精确性不够的地方写进 notes，截图检查连杆端点有没有明显脱开。

## 带 / 链传动、丝杠

- 带 / 链：两个轮 `spin`，speed₂ = speed₁ × D₁ / D₂，**同向**（交叉带反向）。带静止画：上下两段直带（细长 box，切线位置）+ 轮缘，不要让它「走」。
- 丝杠：螺杆 `swing` amp = 圈数 × 360，螺母 `slide` amp = 导程 × 圈数，同 period / phase。

## 棘轮、擒纵、分度

- 一步一格：状态里棘轮 `rot` 每步加 360 / 齿数，`dur` 0.3；棘爪 `swing` 或状态里抬起落下。
- 擒纵：擒纵轮慢 `spin`，擒纵叉 `swing`（amp 8–12°），period = 擒纵轮转一个齿的时间 × 2。演示用，不要求严格咬合，tip 里说明。

## 锁芯、弹子、卡扣

- 剖面：锁芯、壳体只留后半边，弹子、钥匙完整。
- 弹子被顶起：状态里 `at` 升到剪切线；多颗弹子按钥匙齿位依次 `delay`。要「先被钥匙尖顶起、平走、再落进齿槽」时，用 `via`（抛物线途经点）+ 负的 `lift` 拼路径。
- 剪切线、对齐线用细长 `hole` 或 text 标出来。

## 驱动零件（组合运动）

一个零件要同时有两种运动（行星轮既公转又自转、气门只开一段），或者转轴不在零件上时，加一个**驱动零件**当父零件：
```json
{ "id": "drive-in", "name": "进气门正时（隐藏）", "parent": "head", "at": [-14, -4, 0], "rot": [0, 0, 180], "shape": { "type": "text", "text": " ", "size": 0.5 } },
{ "id": "valve-in", "name": "进气门", "parent": "drive-in", "shape": { "type": "cylinder", "r": 15, "h": 2 } }
```
- 驱动零件必须**可见**（shape 是一个空格的 text，看不到）：`visible: false` 的父零件会把子零件一起藏掉。
- 父零件做一个动作、子零件再叠一个（两个 slide 合成「大部分时间关着、只开一段」；行星架 spin + 行星轮 spin）。

## 剖面壳体

- 壳体只留 z ≤ 0（后半边）：`poly` 的 `points` 写 xy 剖面 `[x, y]`，`rot: [-90, 0, 0]`，挤出到 z ∈ [−h, 0]（剖切面正好在 z = 0）。圆筒类用两块半圆环 poly 或 compound。
- 剖切面上的壳体用 `fill: 'shade'`、运动件用 `white` / 真实材质（steel、黄铜色），对比清楚。
- 镜头 `dir` ≈ `[0.2, 0.15, 1]`（正对剖面稍偏），总览 `orbit: false`（转到背面看不见剖面）。

## 拆装（爆炸图）

- 「拆开看」：从整机开始，每步一个零件沿装配方向移开（`at` + `dur` 1.2），移开后留在旁边（别隐藏，读者要看到它在哪）。
- 「装起来」：`start` 把零件放在爆炸位置，每步装回去。装配方向要真实（先装轴、再装齿轮、最后盖盖子），路径不穿过别的零件（必要时 `via`）。

## 常见错误

| 现象 | 原因 / 修法 |
|---|---|
| 齿轮互相穿插 / 有缝 | 中心距 ≠ r₁ + r₂，或模数不同 |
| 齿轮看起来打齿 | 相位不对（齿对齿）：转半个齿距；转速比不是齿数反比 |
| 齿轮转向一样 | 相邻啮合的 speed 要一正一负 |
| 活塞和曲轴对不上 | 曲柄销不在曲柄局部 +x，或 slide 的 phase 不是 0.5、rod ≠ 连杆长、delay 不同 |
| 零件绕错地方转 | 原点不在轴心：形体用 `at` / `pivot` 挪开，让零件原点落在轴上 |
| 加了驱动零件后子零件消失 | 驱动零件写了 `visible: false`：改成一个空格的 text 形体 |
| 剖面挡住运动件 | 壳体挤出方向反了（应该是 z ≤ 0），或镜头从背面看 |
