## 动作的数学

| 动作 | 位移 / 角度 | 正方向 |
|---|---|---|
| `swing` | θ(t) = amp × sin(2π(t / period + phase))（度） | 绕零件局部轴按右手定则：axis z 正 = 从 +z 看逆时针 |
| `slide` | d(t) = amp × sin(2π(t / period + phase))（mm）；给 `rod` 时按曲柄滑块算 | 沿零件局部轴正向 |
| `spin` | 每秒 speed 圈 | 从轴的正方向看**顺时针**（和 swing / rot 相反） |

- `phase`：0 从平衡位置往正向走；0.25 从正向最大开始；0.5 往负向走；0.75 从负向最大开始（「拉起来松手」用这个）。
- `clip: 'pos'` / `'neg'`：只留正半波 / 负半波，另一半停在 0（牛顿摆两端的球、只往一个方向拉的绳子）。
- 动作在本步所有状态过渡结束后才开始，`delay` 可以改；几个动作要同步就写同一个 period / phase / delay。
- 动作作用在零件局部坐标里：**零件原点就是转轴**。子零件跟着父零件的动作走。
- 真实太快（碰撞）或太慢（行星）就放慢 / 加快，并在 tip 里写「放慢约 N 倍」。

## 力学

### 杠杆、天平
- 横梁原点放在支点尖（横梁底面中点），沿 x；`rot: [0, 0, +a]` = 左端（−x）下沉。
- 砝码、钩码挂成横梁的子零件（`parent: 'beam'`，`at` 写刻度位置），横梁一转它们跟着走。
- 判断：M_左 = Σ mᵢ g Lᵢ，M_右同理。相等 → `rot` 0；左大 → 倾到左端碰底座（倾角 = asin(支点高 / 半梁长)）；右大反之。
- 一步：先让砝码出现 / 挪位置（`dur` 0.9），再 `delay` 0.9 让横梁转（`dur` 1.2）。chips 写两边力矩：「左 2 × 9.8 × 0.3 = 5.88 N·m」。

### 滑轮
- 绳子是 `cable`：`from` / `to` 挂在零件上（`at` 局部坐标、`dir` 出线方向），零件动绳子跟着弯。绕过轮槽的半圈单独一段挂在不转的滑轮架上，`slack` 调成半圆。
- 拉动用同周期、同相位的 `slide`（`clip: 'pos'`）：

| 装置 | 物体升 h | 绳端走 | 拉力 |
|---|---|---|---|
| 定滑轮 | `slide` amp h | 反向 h | F = G |
| 动滑轮 | amp h | 同向 2h | F = G / 2 |
| 滑轮组（n 段绳吊着动滑轮） | amp h | n·h | F = G / n |

- 轮子跟着绳子转：`swing` 同 period / clip，amp = 绳走的距离 / 轮槽半径 × 180 / π（度）。
- 弹簧测力计挂在绳端，读数用 text 或 callout（「F = 30 N」）。

### 单摆、牛顿摆
- 摆的零件原点在悬点，球在局部 (0, −L, 0)；`rot: [0, 0, −θ]` = 往左拉起 θ。
- 周期 T = 2π√(L / g)（L 用米）：L = 0.2 m → 0.90 s；L = 1 m → 2.0 s。
- 拉起再松手：上一步 `rot: [0, 0, −θ]`；松手那步状态 `{ "rot": [0, 0, 0], "dur": 0.001 }`，动作 `{ "type": "swing", "part": "p1", "axis": "z", "amp": θ, "period": T, "phase": 0.75 }`（从 −θ 开始，接得上）。
- 牛顿摆「进一个出一个」：左球 `clip: 'neg'`、右球 `clip: 'pos'`，同 amp / period / phase。拉两个出两个同理；中间的球不动。
- 球 = `box` 三边相等 + `chamfer` = 半边长（倒成球）。球之间留 1 mm 缝，审计把球当方块。

### 弹簧振子
- 周期 T = 2π√(m / k)。物体 `slide` amp A、period T。
- 弹簧不能拉长：做成 K 圈，每圈一个零件，第 i 圈 `slide` amp = A × i / K（同 period / phase），整根弹簧看起来均匀伸缩。或者「拉长前 / 拉长后」两份弹簧用 `visible` 切换。

### 斜面
- 斜面：`poly` 画侧面三角形再 `rot: [90, 0, 0]` 立起来，或倾斜的 `slab`。
- 滑块沿斜面走：加一个铰链零件（ghost：`shape: { "type": "text", "text": " ", "size": 0.5 }`，保持可见）放在坡顶、`rot: [0, 0, −θ]`，滑块挂在它下面，沿局部 x 移动（状态 `at` 或 `slide` axis x）。
- 分解力：callouts 标 G、G sinθ、G cosθ、f，数值算好。

### 碰撞、动量
- 小车在导轨上：状态里改 `at`，`dur` = 距离 / 速度（放慢时同比例），先后用 `delay`。弹性碰撞等质量：A 停、B 以同速走；完全非弹性：一起以 v / 2 走（B 挂成 A 的子零件）。
- chips 写碰前碰后的 p = mv 和动能，验证守恒。

### 落体、抛体（频闪法）
状态过渡是缓动插值，速度不是匀加速。要讲清「越落越快」，用**频闪**：同一个球复制 N 份，按相等时间间隔放在 y = h − ½ g t² 的位置（抛体再加 x = v₀t），一份一份依次出现（`visible: true`，`delay` 递增 0.25 s），像频闪照片。只是演示路径时可以用一个球 + `via`（抛物线途经点）。

## 电路

- 底板 + 元件都挂在底板上（`parent: 'board'`）。电池盒、闸刀开关、灯座、电表各是一个零件。
- 闸刀：原点在铰链上，`rot: [0, 0, 50]` 断开、`[0, 0, 0]` 合上（`dur` 0.6）。
- 灯泡发光：灯泡正面一个 `led`，`light: 'on' / 'off'`，`color` 表示亮度（暗：`#ff9a3c` 小 led；亮：`#fff2a0` 大 led，两只 led 用 `light` 切换）。合上开关的那步 led 的 `delay` 等于闸刀的 `dur`，先合上再亮。
- 导线：`cable`，两端挂接线柱顶（`dir: [0, 1, 0]` 向上出线），`slack` 1–1.4，别穿过元件。
- 数字：R = U / I；串联 I 相同、电压分；并联 U 相同、电流分；功率 P = UI 决定谁更亮。chips 写算式。
- 电流方向：可以加一排小球（`r` 1.5 的 led 或小 box）沿导线依次 `visible` 出现表示电流走向，但不要假装是真实电子速度。

## 光路

- 光线：细长 `box`（`size: [长度, 1.5, 1.5]`），`pivot: [长度 / 2, 0, 0]` 让它从原点向 +x 伸出，`rot: [0, 0, 角度]` 定方向；从光源一段段「射出」用 `visible: true` + 递增 `delay`。光线用亮色 `finish: { "color": "#ffd23f", "roughness": 0.3 }`。
- 反射：入射角 = 反射角（相对法线）。折射：n₁ sinθ₁ = n₂ sinθ₂（空气 1.0、水 1.33、玻璃 1.5），算出角度写进 chips。
- 平面镜：薄 `box`；透镜：扁 `cylinder`（axis 沿光轴）；光屏：竖着的 `slab`。凸透镜成像按 1/u + 1/v = 1/f 算像距，像用 text 或倒过来的小模型。

## 波

- 一排 N 个小球沿 x，间距 d：横波每个球 `slide` axis y，amp A，period T，phase = −xᵢ / λ（λ = 波长，波往 +x 传）；纵波 `slide` axis x。
- 驻波：phase 相同、amp = A |sin(2π xᵢ / λ)|（节点 amp 0，相邻腹点 phase 差 0.5）。
- chips：v = λ / T。

## 浮力与液面

- 容器：`cylinder`（`r2` 可做杯口外扩）；水：稍矮一点的 `cylinder`，`finish: { "color": "#8fc9ef", "roughness": 0.1 }`。液面变化 = 两份不同高度的水 `visible` 切换（同一步，`dur` 0.05 换掉）。
- 物体浸入：挂在测力计下 `at` 往下走；读数 F = G − ρ液 g V排，换读数的 text。
- ΔV = 容器截面积 × Δh，用来定水面升多少（数字要对得上）。

## 磁场

- 条形磁铁：两段不同颜色的 `box`（N 红 S 蓝）+ text。
- 小磁针：`poly` 菱形（一半红一半白可以拆两块），`rot: [0, 角度, 0]` 指向该点的磁场方向；磁铁一靠近，磁针状态里转过去。
- 磁感线：`cable` 从 N 极一点到 S 极一点，`slack` 调弯度，`r` 0.6；画 4–6 条对称的。

## 器材速建

| 器材 | 写法 |
|---|---|
| 实验桌 / 底板 | `slab`，`finish: 'wood'` |
| 铁架台 | compound：底座 slab + 立杆 cylinder + 横杆 cylinder（axis x），`finish: 'steel'` |
| 钩码 / 砝码 | `cylinder` + 顶上小钩（细 cylinder），标 text「50 g」 |
| 弹簧测力计 | compound：外壳 box + 刻度 text + 挂钩；读数 text |
| 刻度尺 | 细长 slab + 每 10 cm 一个 text |
| 电池盒 | box + 两个接线柱 cylinder + text「3 V」 |
| 灯座 + 灯泡 | 底座 cylinder + 玻璃泡（box chamfer 成球）+ 正面 led |
| 导线 | `cable`，`r` 1.2 |

## 常见错误

| 现象 | 原因 / 修法 |
|---|---|
| 摆绕着球心转、横梁绕端点转 | 零件原点不在转轴上：把原点放在悬点 / 支点，形体用 `at` 或 `pivot` 挪开 |
| 两个本该同步的东西对不上 | period / phase / delay 不一致；绳端和物体要同一组 |
| 松手时摆跳了一下 | swing 的 phase 没用 0.75，或松手那步 rot 没在 0.001 s 内回到 0 |
| 动起来穿过桌面 / 支架 | 审计不看动作：按最大幅度算一遍间隙（摆最低点、活塞下止点） |
| 灯一直亮着 / 亮早了 | led 的 light 写在了开关合上之前；用 delay 等开关合上 |
| 数字前后对不上 | 先在 notes 里把每一步的计算写全，再抄进 chips / callouts |
