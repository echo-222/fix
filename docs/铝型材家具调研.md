# 铝型材家具调研（v0.1 · 以桌子为例）

> 目的：为「说明书 → 3D 安装 / 修复指导」第一版确定支持范围、参数模型和安装规范。
> 数据来源：嘉立创 TXCJ 欧标 20 系列、怡合达欧标 30 系列、HA01 欧标 40 系列选型手册；Phidgets T-Slot Guide、Maker Hardware 桌子装配手册、AutomationDirect SureFrame 工作台教程；国标 GB/T 3326《家具 桌、椅、凳类主要尺寸》。

## 1. 什么是铝型材家具

工业铝型材（T 型槽型材）原本用于设备机架和流水线，材质多为 **6063-T5 阳极氧化**。截面四周带 T 型槽，通过 T 型螺母 + 角码即可在任意位置连接，不需要焊接或打孔，因此近几年被大量用于 DIY 家具：书桌、电竞桌、站立工作台、显示器架、置物架、床架等。

| 优点 | 缺点 |
| --- | --- |
| 模块化，尺寸可任意定制（按 0.5mm 下料） | 工业感强，需要槽封条 / 端盖修饰 |
| 免焊接、可拆装、可二次改装（加挂架、线槽） | 单价高于钢管家具 |
| 强度高、不生锈 | 零件多（一张桌子 150+ 五金），装错顺序要返工 |
| 配件生态成熟，电商可直接按清单下单 | 新手不熟悉槽宽 / 螺纹匹配，容易买错 |

最后两条缺点正是本产品要解决的：**零件多 + 顺序敏感 + 规格易错**。

## 2. 常用规格（欧标）

| 规格 | 槽宽 | 中心孔 | 端面攻丝 | 配套螺丝 | 米重 | 惯性矩 Ix | 典型用途 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 2020 | 6.2mm | Ø5 | M6 | M5 | 0.49kg | 0.73×10⁴ mm⁴ | 显示器架、小边桌 |
| 3030 | 8.2mm | Ø6.8 | M8 | M6 | 0.85kg | 2.74×10⁴ mm⁴ | 1.2–1.4m 书桌框架 |
| 4040 | 8.2 / 10.2mm | Ø6.8 | M8 | M8 | 1.60kg | 8.4×10⁴ mm⁴ | 桌腿首选 |
| 4080 | 8.2mm | 2×Ø6.8 | M8 | M8 | 2.87kg | 62.9×10⁴（竖放） | 长桌主梁、重载工作台 |

要点：
- **欧标与国标配件不通用**（同为 4040，国标槽宽 10mm，欧标有 8 槽和 10 槽两种）。App 生成清单时必须标明「欧标 + 槽宽」。
- 4080 竖放的抗弯能力约为 4040 的 7.5 倍，是长桌防下沉最经济的手段。
- 长度公差一般 ±0.5mm，切口不做氧化处理。

## 3. 连接方式

| 方式 | 是否需要加工 | 外观 | 适用 |
| --- | --- | --- | --- |
| 压铸角码 + T 型螺母 | 否 | 角码外露 | 新手首选，v1 默认 |
| 内置锚式连接件 | 横梁端部需打工艺孔（可让商家代加工） | 隐藏 | 追求外观 |
| 端面攻丝 + 螺丝直连 | 中心孔攻丝 | 隐藏 | 需要丝锥 |
| 连接板（平板） | 否 | 外露 | 两根平行型材拼接（如挂架立柱） |

**T 型螺母分两类，决定了安装顺序：**
- 滑入式：只能从型材端部滑入，强度高、便宜 —— 必须在框架闭合前预装。
- 弹片 / 落槽式：可以从槽口直接放入后旋转 90° 卡紧 —— 用于框架闭合后的加强梁、线槽、桌面固定片。

> 新手最常见的返工：框架装完才发现少放了螺母。App 的步骤里会在「闭合后」的步骤自动切换成弹片螺母，并在细节动画里演示「放入 → 旋转 90°」。

40 系列接头建议每处 2 个角码（底部 + 内侧），20/30 系列 1 个。

## 4. 桌子结构设计要点

尺寸参考（GB/T 3326）：坐姿桌面高 680–760mm；常见宽 1000–1800mm、深 550–800mm；站立桌 950–1150mm。

| 设计项 | 建议 |
| --- | --- |
| 桌腿 | 4040；高桌或重载用 4080（80 面沿进深方向） |
| 前后主梁 | 跨度 ≤ 1.2m 用 4040；> 1.2m 用 4080 竖放 |
| 下横撑 | 推荐 U 型（两侧 + 后），不挡腿又能大幅减少前后晃动；站立桌用四周闭合 |
| 中间加强梁 | 框架宽 > 1.3m 时添加，支撑桌面中部 |
| 桌面外伸 | 30–80mm；> 100mm 按压边缘会翘 |
| 脚 | M8 调节脚杯（桌腿底部中心孔攻丝 M8）；脚轮仅用于低桌 |
| 桌面固定 | L 型固定片 + 弹片螺母，木螺丝长度 ≤ 板厚 − 6mm |

App 内置的结构估算：
- 横梁下挠：简支梁均布载荷 δ = 5wL⁴ / 384EI（E = 69GPa），并给出 30kg 中点按压的 δ = PL³ / 48EI。
- 晃动指数：桌腿长细比 ÷ 下横撑系数 ÷ 接头系数，属于经验值，用于对比方案而非精确计算。

## 5. 标准安装流程

1. 清点零件（按长度分组）
2. 组装左右侧框（预装滑入式 T 型螺母）
3. 连接前后横梁
4. 安装下横撑
5. 安装中间加强梁（改用弹片螺母）
6. 量对角线检查方正（差值 ≤ 2mm），再按对角顺序统一拧紧
7. 安装脚杯 / 脚轮
8. 安装桌面
9. 安装配件（线槽、挂架、封条、端盖）
10. 调平

常见错误：未方正就拧死；螺丝过长顶到槽底导致假紧；T 型螺母没转正导致空转；桌面木螺丝穿透。

## 6. 常见故障与修复（v1 已内置 3 套）

| 故障 | 主要原因 | 修复 |
| --- | --- | --- |
| 桌子晃动 | 接头松动、框架不方正、脚杯未着地、没有下横撑 | 拧紧角码 → 量对角线 → 调脚杯 → 加装下横撑 |
| 桌面中部下沉 | 主梁跨度过大、缺中间梁 | 加中间加强梁 → 换 4080 主梁 |
| 脚杯 / 脚轮损坏 | 滑丝、轮子损坏 | 抬起一角更换，滑丝改用脚杯连接板 |
| 横梁下滑（后续） | 角码螺丝松、螺母未卡正 | 松开 → 复位 → 重新拧紧 |

## 7. 产品化思路

**AI 不直接生成 3D，而是生成「参数化规格」。** 说明书照片 → 多模态模型抽取 JSON（尺寸、型材、连接方式、配件、零件表、原步骤，以及每个字段的依据）→ 确定性生成器计算零件坐标、切割清单、五金数量、步骤动画。这样做的好处：
- 结果可复现、可校验（零件数、长度都能和说明书零件表对账）；
- 识别不准时用户直接改参数，不需要重新拍照；
- 结构评估、清单导出、修复指南都复用同一份模型。

扩展路线：
1. v1：铝型材桌子（本版本）
2. v1.x：把桌子生成器抽象成「节点 + 杆件 + 接头」的通用框架图，支持置物架、显示器架、床架
3. v2：PDF 多页导入；拍照识别实物零件（核对是否缺件）；商家一键下单；AR 叠加安装指引
4. v3：非铝型材家具（板式家具的偏心件 / 木榫）
