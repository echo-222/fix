# 修理工 · 3D 说明书

拍照 / 上传家具说明书，AI 解析后生成可交互的 3D 安装与修复指导。目前支持**铝型材书桌**和三款**光轴家具**（落地置物架、边几、挂衣架），都可自定义尺寸、材料和配件。菜单 →「选择家具」切换。

## 运行

```bash
npm install
npm run dev          # 打开终端显示的地址；手机连同一局域网可用 Network 地址访问
```

### 配置 AI（可选）

```bash
cp .env.example .env.local   # 填写 AI_API_KEY
```

任何兼容 OpenAI Chat Completions、支持图片输入的模型都可以（OpenAI gpt-4o、通义千问 qwen-vl-max 等）。Key 只保存在本地开发服务器，不会发到浏览器。未配置时，导入流程会使用示例解析结果演示。

## 功能

- **安装指南**：按配置自动生成 9–12 步，每步新零件以红色线稿飞入、内六角扳手动画、右上角「细节」圆窗演示接头（T 型螺母滑入、弹片螺母旋转、角码、脚杯、连接板等）。
- **修复指南**：桌子晃动、桌面下沉、更换脚杯 / 脚轮，必要时用红色虚线显示建议加装的零件。
- **自定义设计**：尺寸、桌腿 / 横梁型材、连接方式、下横撑、中间梁、脚、线槽、后挂架、桌面材质，实时给出下挠、晃动、重量、参考价和结构警告。
- **零件清单**：型材切割清单（按长度合并，可直接发给商家）、五金、工具，支持复制和导出 JSON。
- **导入说明书**：拍照或上传最多 8 页，AI 抽取参数，并标注每个参数来自说明书还是默认值（目前只解析铝型材桌子）。

### 光轴家具

三款各用一种典型连接方式，光轴直径 Ø10–20、镀铬 / 304 不锈钢可选：

| 家具 | 连接方式 | 可自定义 |
|---|---|---|
| 光轴落地置物架 | 光轴穿板，限位环托住层板，底层 / 顶层上下夹紧 | 尺寸、层数、板材、调节脚 / 脚套、背部加强横杆、单层载重 |
| 光轴边几 | SHF 法兰支座木螺丝固定在桌面下，倒置组装后翻正 | 尺寸、法兰内缩、下层板及高度、底脚 |
| 光轴挂衣架 | T 型夹（盲孔插立柱）+ 十字夹（两通孔） | 立柱间距、高度、挂衣杆外伸、鞋架横杆、加强横杆、挂衣重量 |

结构评估（层板 / 挂衣杆下弯、限位环 / 夹具防滑承载、长细比）为经验估算，承载值假设光轴已擦净防锈油、顶丝拧紧。

### 电子产品说明书（场景脚本）

非参数化的说明书（电子产品、小家电、工具）用一份**场景脚本**描述：零件由基本形体拼成，每一步只写状态变化（移动 / 换父级 / 开关档位 / 指示灯 / 屏幕界面 / 线缆），编译器校验后生成通用的指南步骤。

第一份是**蓝牙无线鼠标**（菜单 → 选择家具 / 说明书 → 蓝牙无线鼠标），5 页说明书 → 5 个指南 33 步：

| 指南 | 步数 | 原说明书 |
|---|---|---|
| 2.4G 连接 · USB-A 接收器 | 9 | 第 1–3 页（含清点包装、顶部按键、底部结构） |
| 2.4G 连接 · Type-C 接收器 | 6 | 第 4 页 |
| 蓝牙连接 | 6 | 第 4 页（电脑上的蓝牙设置界面逐屏演示） |
| 充电 | 4 | 第 5 页（红灯 / 绿灯、充电线实时弯曲） |
| 连不上？逐项排查 | 8 | 第 4–5 页 |

每步标注原文页码，「包装与参数」面板里可查看包装清单、基本参数和原说明书照片。

新增说明书：按 `.cursor/skills/manual-to-3d/SKILL.md` 的流程写 `src/domain/manual/library/<id>.ts`，加到 `library/index.ts`，再运行 `npm run check:manuals` 校验。

快捷键：← → 切换步骤，空格播放 / 暂停。

## 结构

```
server/            Vite 中间件：/api/analyze 调用多模态模型，prompt 定义参数 JSON
src/domain/        纯逻辑：型材数据、桌子生成器（零件 / 清单 / 结构评估）、步骤生成
src/domain/shaft/  光轴家具：规格表（光轴 / 限位环 / SHF / 夹具 / 板材）、三款生成器与安装 / 修复步骤
src/domain/manual/ 说明书场景脚本：类型定义、编译校验、library/ 下每份说明书一个文件
src/three/manual/  场景脚本渲染：形体几何、状态插值与动作、指示灯、屏幕界面、线缆
public/manuals/    说明书原图
scripts/           check-manuals.mjs：校验所有场景脚本
.cursor/skills/    manual-to-3d：把任意说明书变成 3D 交互演示的流程
src/ai/            图片压缩、调用解析接口、JSON → 配置校验、示例数据
src/three/         线稿渲染（白色填充 + 描边）、主场景动画、细节圆窗场景
src/ui/            顶栏、步骤信息、时间轴、菜单、设计面板、清单、导入弹窗
docs/              铝型材家具调研
```

调研结论与设计依据见 [docs/铝型材家具调研.md](docs/铝型材家具调研.md)。
